# Депо без сна

*Последний трамвай. Первый эспрессо.*

Ночные бариста делят городские заказы. Возьми заказ, поймай нужный трамвай и приготовь напиток так, чтобы передать его горячим. У каждого заказа есть последний ход, в который клиент ещё ждёт.

## Запуск в Docker

В каталоге `sinica` собери образы и подними сервер.

```powershell
docker compose --profile play build
docker compose up -d --wait server
```

Открой клиент в одном терминале.

```powershell
docker compose run --rm client
```

Когда будешь готов начать смену, запусти бота в другом терминале.

```powershell
docker compose run --rm bot
```

Другого игрока можно подключить ещё одной командой `docker compose run --rm client`. Сервер также принимает обычное TCP-подключение в UTF-8 на `127.0.0.1:4040`.

## Как играть

| Команда | Что делает |
| --- | --- |
| `меня зовут Мира` | Войти под свободным именем из одного слова |
| `покажи карту`, `что по заказам` | Посмотреть состояние города |
| `беру заказ 1` | Забрать свободный заказ |
| `еду на 6` | Проехать одну остановку, если трамвай № 6 сейчас здесь |
| `варю эспрессо` | Приготовить напиток из взятого заказа |
| `отдаю заказ` | Отдать горячий напиток на нужной остановке |
| `жду` | Пропустить ход |
| `выхожу` | Выйти и освободить взятый заказ |

Каждое успешное игровое действие продвигает общий ход и все трамваи. У бариста одновременно один заказ. «До N» означает, что отдать напиток можно и на ходу N. Смена заканчивается, когда все заказы доставлены или просрочены. Побеждает бариста с наибольшим числом доставок.

Быстрый пример на свежем сервере — войди, возьми заказ 1, свари эспрессо, один раз подожди, садись на 6-й трамвай и отдай заказ на «Луче».

Чтобы начать новую смену, перезапусти сервер командой `docker compose restart server`. Чтобы остановить проект, используй `docker compose down`.

## Где менять тему

- `server/src/sinica/tcp.clj` принимает UTF-8 строки. Он хранит мир и подключения в `ref`, меняет их через `dosync` и после транзакции рассылает свежий снимок. Реплика и событие начинаются с `Ответ` и `Событие` соответственно. Строка `Конец` завершает кадр.
- `server/src/sinica/depot.clj` содержит начальное состояние, команды и формирование снимка. Для другой темы передай в `sinica.main` новую игру с полями `:title`, `:initial-state`, `:join`, `:leave`, `:command` и `:snapshot`. Функция команды возвращает пару `[новое-состояние сообщение]`.
- `bot/depot.pl` разбирает снимки грамматикой DCG, обновляет факты и описывает возможные действия для A*. Бот выбирает самый быстрый выполнимый заказ по текущему снимку, отправляет один ход и строит план заново. Для другой темы подставь в `bot/main.pl` модуль с предикатами `remember/1`, `choose/2` и `finished/0`.
- `bot/search.pl` реализует A* для действий стоимостью в один ход. `prolog/net.pl` открывает соединение, а `client/main.pl` передаёт команды и показывает ответы. Эти файлы общие для любой темы с таким текстовым протоколом.
